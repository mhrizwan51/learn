کوئز ۳: قرآنی آیات

سبق ۲ · واحد تثنیہ جمع

کوئز ۱ · بنیادی باتیںکوئز ۲ · پہچانکوئز ۳ · قرآنی آیاتکوئز ۴ · مشقکوئز ۵ · جائزہ
  1. «فَذَانِكَ بُرْهَانَانِ مِن رَّبِّكَ» (القصص ۳۲) میں «بُرْهَانَانِ» کون سا عدد ہے؟
    • تثنیہ
    • جمع سالم
    • جمع مکسر
    • واحد
  2. «وَلِمَنْ خَافَ مَقَامَ رَبِّهِ جَنَّتَانِ» (الرحمٰن ۴۶) میں «جَنَّتَانِ» کیا ہے؟
    • تثنیہ مؤنث: دو باغ
    • جمع مؤنث سالم: بہت سے باغ
    • جمع مکسر
    • واحد مؤنث
  3. «مَرَجَ الْبَحْرَيْنِ يَلْتَقِيَانِ» (الرحمٰن ۱۹) میں «الْبَحْرَيْنِ» کا مطلب کیا ہے؟
    • ایک دریا
    • بہت سے دریا
    • دریا والے
    • دو دریا (دو سمندر)
  4. «فُتِحَتْ أَبْوَابُهَا» (الزمر ۷۱) میں «أَبْوَابُ» کون سی جمع ہے اور اس کا واحد کیا ہے؟
    • تثنیہ؛ واحد بَابٌ
    • جمع سالم؛ واحد بَابٌ
    • جمع مکسر؛ واحد بَابٌ
    • جمع مکسر؛ واحد بَوَّابٌ
  5. «فَوَيْلٌ لِّلْمُصَلِّينَ» (الماعون ۴) میں «الْمُصَلِّينَ» کون سا عدد ہے؟
    • تثنیہ
    • جمع مذکر سالم
    • جمع مکسر
    • واحد
  6. «ثُمَّ رَدَدْنَاهُ أَسْفَلَ سَافِلِينَ» (التين ۵) میں «سَافِلِينَ» کیا ہے؟
    • تثنیہ
    • جمع مذکر سالم
    • جمع مکسر
    • واحد
  7. «وَتَكُونُ الْجِبَالُ كَالْعِهْنِ الْمَنفُوشِ» (القارعة ۵) میں «الْجِبَالُ» کیا ہے؟
    • تثنیہ
    • جمع مذکر سالم
    • جمع مکسر؛ واحد جَبَلٌ
    • واحد
  8. «ثُمَّ قَسَتْ قُلُوبُكُم» (البقرة ۷۴) میں «قُلُوبُ» کون سی جمع ہے؟
    • تثنیہ
    • جمع مؤنث سالم
    • جمع مذکر سالم
    • جمع مکسر
  9. «الَّذِينَ هُمْ عَن صَلَاتِهِمْ سَاهُونَ» (الماعون ۵) میں «سَاهُونَ» کیا ہے؟
    • تثنیہ
    • جمع مذکر سالم
    • جمع مکسر
    • واحد
  10. «وَبِالْوَالِدَيْنِ إِحْسَانًا» (البقرة ۸۳) میں «الْوَالِدَيْنِ» کیا ہے؟
    • تثنیہ: ماں اور باپ
    • جمع مذکر سالم
    • جمع مکسر
    • واحد
