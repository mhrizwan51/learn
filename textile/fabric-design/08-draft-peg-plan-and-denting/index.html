Fabric Design · Lecture 08

Draft, Peg Plan and Denting

From design to loom: which heald carries each end, which healds lift on each pick, and how many ends go through each reed dent.
DraftPeg planHealdsDenting

Three drawings for every weave

  1. Design — the point paper: ends across, picks up.
  2. Draft — one row per heald frame: ends that move identically go on the same heald. The number of different end movements = number of healds.
  3. Peg (lifting) plan — one column per heald, one row per pick: which healds rise on each pick. For a straight draft the peg plan is the design itself.

The engine on every weave page computes the draft and peg plan automatically; here they are shown for a straight-drafted twill and a pointed twill.

3/1 twill — straight draft · 8 ends × 8 picks

Draft · 4 healds

Threading order: 1 2 3 4 1 2 3 4

Lifting (peg) plan

4 healds for 8 ends: end 5 moves like end 1, so both go on heald 1. Threading 1 2 3 4 1 2 3 4.

Pointed twill — pointed draft · 6 ends × 8 picks

Draft · 4 healds

Threading order: 1 2 3 4 3 2

Lifting (peg) plan

Threading 1 2 3 4 3 2: the draft turns back, the peg plan stays a plain 2/2 twill.

Denting

Ends are drawn through the reed in groups — 2, 3 or 4 per dent — chosen so that the group matches the weave repeat (or divides it) and the ends in a dent are not all lifting together, which would leave reed marks.

WeaveEnds per dentWhy
Plain 1/12one up, one down in each dent
2/1 twill3whole repeat per dent
3/1 twill, 2/2 twill4whole repeat per dent
5-end satin2, 3 alternately (2.5 avg)repeat does not divide by 2 or 4

Reed count then follows from EPI ÷ ends per dent (Weaving Calculations 11).
